# Deploy HD2Lab

This is the complete static website package. `index.html` is at the archive root, alongside `styles.css`, `data.js`, `app.js`, `report-pdf.js`, and the `assets/` folder. No build tools or external runtime packages are required.

## GitHub Pages

1. Extract the ZIP. In your GitHub repository, replace the site files with the contents of the extracted folder (not the folder itself).
2. Commit your changes to the branch GitHub Pages publishes (usually `main`).
3. Make sure Settings → Pages → Build and deployment uses the branch and `/ (root)`.
4. Refresh your published site after deployment. If the old version remains visible, hard-refresh or clear site cache.

## Netlify

Drag and drop the ZIP into https://app.netlify.com/drop, or deploy the extracted directory.

## Included

The five built-in aesthetics, Scope of Authority Warbond loadout entries, Sniper Rifles category, loadout synergy engine, randomizer, PDF exporter, and original 101st logo are all local to this package.
